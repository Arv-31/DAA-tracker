DAA Tracker
A simple checklist to track progress through Design and Analysis of Algorithms (DAA) topics — Divide and Conquer, Greedy, Dynamic Programming, Backtracking, Branch and Bound, Graph Algorithms, and Complexity Theory.
Usage
Just open index.html in a browser. Check off topics as you study them — progress is saved automatically in your browser and shown as a percentage.
Deploying on GitHub Pages (optional)
	1.	Push this repo to GitHub.
	2.	Go to Settings → Pages.
	3.	Under “Source,” select the main branch and / (root) folder.
	4.	Your tracker will be live at https://<username>.github.io/<repo-name>/.
